# kmorido をこれから触るAIへ

FastAPI ＋ SQLite ＋ shapely。データは国土数値情報 A56（宅地造成等工事規制区域・特定盛土等規制区域）。

## 先に読むもの

- `README.md` の「設計の芯」4項目。ここを崩すと製品の意味が無くなる。
- `app/codes.py` の冒頭コメント。**コードリストは国交省が公開していない**ので、
  どうやって確定したかを書いてある。勝手に書き換えない。

## よくある誤り

- **コード9を「その他」と訳す。** 違う。**「両方の区域を指定していて区分が分かれていない」**（5,544件）。
  国交省の指定状況一覧（https://www.mlit.go.jp/toshi/content/001893613.pdf）で、
  該当団体が宅造区域と特盛区域の両方に面積を持っていることを確認済み。
  「その他」「不明」と出すと、利用者は「規制が無いのかも」と誤解する。
- **「区域外」と「未指定」を混ぜる。** 青森・香川・佐賀・沖縄はまだ指定・公開していない。
  盛土規制法は2023年5月施行で指定が進行中。黙って「区域外」と答えると
  「規制が無い土地だ」と誤解される。`Index.covers_pref()` が分けている。
- **市区町村単位で covers を判定する。** A56 は知事が県全体を見て指定するので、
  「県内に指定はあるが、この市には無い」は正常（＝区域外）。**都道府県単位**で見ること。
  （kriskarea の A48 は自治体が条例で指定するので市町村単位。設計が違う）
- **PostGIS を持ち込む。** 10万件なら STRtree で足りる。起動23秒・判定0.1〜50ms。
- **「盛土がある場所」と説明する。** 違う。「工事に許可・届出が要る範囲」。
  大規模盛土造成地マップ（重ねるハザードマップ）とは別物。ここを混ぜると製品価値が消える。

## データ更新

A56 は年度更新（2025年度版がある）。更新するときは:

1. 一覧 `https://nlftp.mlit.go.jp/ksj/index.html` から最新年度のページを辿る。
   **旧年度のページは「最新」と書いたまま更新されない**ので、直リンクを信用しない。
2. `scripts/load_a56.py` の `BASE`（`A56-25` の部分）と `VINTAGE` を新年度に合わせる。
3. 再取り込み後、`area_type_code` の分布を必ず確認する。
   **1/2/9 以外のコードが出たら、推測でラベルを付けずに国交省の一覧で裏を取る。**
   ローダーは未知コードを検出したら「（未知のコード: …）」と表示する。
4. 未指定だった県が指定を始めていないか確認する（配布なしの一覧が減る）。
