# Kurage 盛土規制区域マップ (kmorido)

住所を入れると、その土地が**盛土規制法**（宅地造成及び特定盛土等規制法）の
「宅地造成等工事規制区域」「特定盛土等規制区域」に入っているかを、
**告示番号・施行年月日つき**で返す。

- 公開: https://kurage.exbridge.jp/kmorido.php/
- バックエンド: `127.0.0.1:18312`（user unit `kmorido.service`）
- 収録: **104,309区域 / 1,539市区町村 / 43都道府県**（2025年度版・2025-07-18時点）

## 大規模盛土造成地マップとの違い（この製品の芯）

| | |
|---|---|
| 大規模盛土造成地マップ | そこに**盛土がある**という土地の成り立ち。重ねるハザードマップにある |
| **盛土規制法の規制区域** | そこで盛土・切土をするには**許可・届出が要る**という法的な線 |

宅地造成等工事規制区域は**宅地建物取引業法35条の重要事項説明の対象**。
それなのに実務の調査方法は「◯◯県 宅地造成工事規制区域」でGoogle検索して
県ごとのPDFを探す、という状態で、住所で引ける横断的な道具が無かった。

## データ

- 国土数値情報 **A56**（宅地造成等工事規制区域・特定盛土等規制区域）／国土交通省
- **CC BY 4.0**。出典表示だけで商用利用できる（A48 と違い自治体ごとの条件差が無いので除外リストは持たない）
- **申請資料には使えない**。配布元が「概略的な位置であり法的図書ではない」と明記している
- 未指定4県: 青森県・香川県・佐賀県・沖縄県 →「区域外」ではなく**「未指定」**と返す

### 規制区域区分コード（A56_004）は実データで確定した

配布ページは「コードリスト参照」のリンクだけで**対応表が公開されていない**。
そこで `app/codes.py` に書いたとおり、告示番号(A56_006)の発行者と突き合わせて確定した。

- **9 を「その他」と訳してはいけない。「両方の区域を指定していて区分が分かれていない」**（5,544件）。
  宇部市の告示が「山口県告示第227号_228号」と2本連結で、国交省の指定状況一覧
  （令和7年6月1日現在）でも山口県は宅造区域191,134ha ＋ 特盛区域348,439ha の両方を全域指定だった。
- 指定主体 A=都道府県 / B=指定都市 / C=中核市（告示の発行者と完全一致）

## 設計の芯（kriskarea と同じ約束）

1. **「区域外」と「未指定」を必ず区別する。** 盛土規制法は2023年5月施行で指定が進行中。
   未指定の県で黙って「区域外」と答えると「規制が無い土地だ」と誤解される
2. 判定には必ず根拠（告示番号・施行年月日・指定主体）とデータ時点を添える
3. 代表点なので、近くに区域があるときは距離を添えて言い切らない（250m以内）
4. **区域外は安全という意味ではない。** これは「工事に許可が要る範囲」であって危険度ではない

## 動かす

```
/usr/bin/python3 scripts/load_a56.py          # データ取り込み（全国・約5分）
systemctl --user enable --now kmorido.service # 常駐
bash scripts/deploy_proxy.sh                  # 公開入口をhetemlへ
```

PostGIS も Docker も要らない。10万件なら SQLite + shapely の STRtree で足りる
（索引の構築は起動時に約23秒、判定は1件0.1〜50ms）。

## 大規模盛土造成地（A54）も同じ住所で返す（2026-09-21 追加）

上の表で「別のもの」と書いた**大規模盛土造成地**を、同じ判定に足した。
規制区域（A56）は「工事に許可が要る線」、大規模盛土造成地（A54）は「そこに盛土がある事実」。
両方を1回の住所判定で返す。

- 取り込み: `/usr/bin/python3 scripts/load_a54.py 23`（都道府県コード。省略で全国）
- 収録（愛知県）: **3,674地区**（名古屋市626・豊田市331・岡崎市296…）
- 盛土区分は国の対応表どおり **1=谷埋め型 / 2=腹付け型 / 9=区分をしていない**
  （`codelist/fillSlopeClassification.xlsx` を取得して確認。当社で推測した名前は付けていない）
- データ基準は2023年3月31日。CC BY 4.0
- API は `fill_slope` キーで返す（`status` は inside / outside / uncovered）
- **取り込んでいない県では「区域外」と言わない。**「データをまだ取り込んでいません」と書く

### 配布が GML しかない

A54 は Shapefile も GeoJSON も無く、ksj 独自スキーマの GML（XML）だけ。
GDAL の GML ドライバでもレイヤとして開けない（xlink 参照のため）。
`scripts/load_a54.py` が自前で読む（Curve→Surface→Feature の3段を解決。座標は緯度経度の順）。
